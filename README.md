# 🛒 Amazon Sales Dashboard – Power BI

## 📌 Project Overview

The **Amazon Sales Dashboard** is an interactive data visualization project developed using **Microsoft Power BI**. 

The dashboard is designed to analyze Amazon sales data and provide meaningful insights into sales performance, products, order status, sellers, and geographical sales distribution.

## 🎯 Project Objective

The main objective of this project is to transform raw Amazon sales data into an interactive and easy-to-understand dashboard that helps users identify:

- Overall sales performance
- Sales by state and city
- Product-wise performance
- Order status distribution
- Sales trends over time
- Seller performance

## 📊 Dashboard Features

- 💰 **Total Sales KPI**
- 👥 **Seller Count**
- 📦 **Order Status Analysis**
- 🌍 **Sales by State**
- 🏙️ **Sales by City**
- 🛍️ **Product-wise Analysis**
- 📈 **Sales Trend Analysis**
- 🔎 **Interactive Filters and Slicers**
- 🖼️ **Product Images**
- 💡 **Interactive Tooltips**
- 🔄 **Sales and Units View**

## 🛠️ Tools & Technologies

- **Microsoft Power BI**
- **Power Query**
- **DAX**
- **Data Cleaning**
- **Data Transformation**
- **Data Visualization**

## 📈 Key Insights

The dashboard helps users understand:

- Which states generate higher sales
- Which cities contribute significantly to sales
- Product-level sales performance
- Distribution of different order statuses
- Sales trends across different dates
- Overall business performance
